# Code of Conduct

Tervano contributors and users should be able to discuss technical work without
harassment. Be respectful, assume good intent where reasonable, and focus
feedback on behavior and code. Disagreement and direct criticism are welcome;
personal attacks, threats, discriminatory language, sexual harassment, and
sharing another person's private information are not.

This applies in project issues, reviews, discussions, and other project spaces.
Maintainers may remove harmful content, ask someone to change their behavior,
restrict participation, or ban repeated or severe violations. They will consider
context and the safety of people involved when responding.

For conduct concerns, contact a maintainer privately through an available
GitHub profile contact method. If there is no private route, use GitHub's abuse
reporting tools. Do not post sensitive personal details in a public issue.
Security vulnerabilities have a separate reporting path in [SECURITY.md](SECURITY.md).
